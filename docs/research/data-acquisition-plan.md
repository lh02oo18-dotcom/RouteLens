# CAVIAR 真实数据试采与审计

## 数据充分性结论

状态：`SUFFICIENT_FOR_SMALL_PILOT`

仓库原有 `data/videos/smoke.mp4` 只用于运行链路冒烟测试。现已补充三段带逐帧人物框、身份和行为字段的 CAVIAR 实拍视频，足以支持小样本比较，但仍不足以支持开放世界或跨摄像机推广。

## 数据来源与使用边界

- 来源：爱丁堡大学 CAVIAR Test Case Scenarios。
- 官方页面：https://homepages.inf.ed.ac.uk/rbf/CAVIARDATA1/
- 数据性质：室内大厅与商场场景的实拍、情景化演示视频；不是合成数据，也不等同于自然发生的真实犯罪或安全事件。
- 授权：官方页面标注为 Creative Commons BY-SA；论文和报告需致谢 EC Funded CAVIAR project/IST 2001 37540。
- 获取方式：只使用官方直接下载链接，不使用镜像、不抓取受限页面。
- 隐私边界：仅用于非商业研究和算法评估；不做人脸识别、身份推断或个人画像。

## 试采方案

- 分析单元：视频帧中的人工标注人物框、跨帧身份轨迹，以及由官方行为字段或人工轨迹规则定义的事件区间。
- 纳入条件：可从官方页面直接下载；同时提供 MPEG 视频与 XML 标注；OpenCV 可解码；XML 可解析；含至少一个人物轨迹。
- 排除条件：缺失视频或 XML、文件损坏、许可不清、无法稳定解码、与行人轨迹无关。
- 时间范围：CAVIAR 页面列出的 2003–2004 年录制片段。
- 地理范围：法国 Grenoble 的 INRIA 室内大厅场景；后续扩展可加入葡萄牙 Lisbon 商场场景。
- 语言范围：英文元数据和行为标签。
- 关键字段：`frame.number`、`object.id`、`box`、`movement`、`role`、`context`、`situation`。
- 预期规模：先试采 3 段，共 3,570 个视频帧；审计通过后再扩充到预注册的正式子集。
- 输出格式：原始 MPEG/XML 保存在被 Git 忽略的 `data/raw/caviar/`；可提交的清单、脚本、配置和汇总指标保存在仓库中。
- 停止规则：3 段均可解码和解析，且覆盖正常行走、往返浏览、长时间等待三类场景，即停止试采并进入人工审计。

## 试采结果

| 序列 | 视频帧 | 标注帧 | FPS | 分辨率 | 主要用途 |
|---|---:|---:|---:|---:|---|
| Walk1 | 618 | 611 | 25 | 384×288 | 正常行走对照、检测与跟踪 |
| Browse1 | 1,050 | 1,043 | 25 | 384×288 | 往返浏览、轨迹与事件 |
| Browse_WhileWaiting2 | 1,902 | 1,895 | 25 | 384×288 | 长时间等待/浏览事件 |

三个序列均通过首帧解码与 XML 解析。视频帧数比标注帧数各多 7 帧，正式评估必须按 XML 中实际存在的 `frame.number` 对齐，不能假设每一帧都有标注。文件大小和 SHA-256 校验值见 `caviar-pilot-manifest.csv`。

## 预注册的验证设计

1. 人物检测：以人工框为参照，报告 IoU=0.50 下的 Precision、Recall、F1，以及每段视频的漏检/误检数。
2. 轨迹质量：报告标注轨迹覆盖率、匹配框中心误差、身份切换数和每秒处理帧数。
3. 事件识别：浏览/等待标签用于构造可审计的 loitering 参考区间；reverse-direction 参考区间只从人工轨迹按预先固定的方向规则派生，并在结果中明确标为“轨迹规则派生”，不冒充官方行为标签。
4. 对比实验：YOLO11n+ByteTrack 为主方法，YOLO11n+BoT-SORT 为跟踪器对照；若电脑资源允许，再加入 CSRT 解释性基线。
5. 可复现性：固定数据清单、模型名、阈值、随机种子、命令、软件版本和结果文件；原始数据不提交到 Git，只提供官方下载脚本和校验值。

## 审计检查点

- 真实性：实拍视频，场景行为为项目成员情景化演示。
- 完整性：3/3 视频可解码，3/3 XML 可解析；标注帧与视频帧存在已记录的固定差异。
- 代表性：足以完成小样本验证，但不能代表开放世界监控场景。
- 偏差：分辨率较低、数据年代较早、场景和人员有限、动作经过编排。
- 许可与来源：官方公开页，CC BY-SA，来源和致谢要求已记录。
- 当前限制：已完成模型推理与描述性比较，但只有一个调参序列和两个测试序列，不进行显著性检验或总体性能外推。完整结果见 `real-data-results.md`。
