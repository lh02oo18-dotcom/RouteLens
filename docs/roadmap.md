# RouteLens 迭代路线图

## v0.1.0：可运行基线与仓库治理

目标：证明开源底座能在目标电脑稳定运行，并建立可追溯的协作流程。

- [x] 建立 `feature/routelens-baseline` 分支
- [x] Python 3.12 虚拟环境与 RTX 4060 CUDA 验证
- [x] YOLO11n + ByteTrack 冒烟测试和 CSV/JSON/MP4 导出
- [x] 测试、代码规范和 Streamlit 健康检查
- [x] RouteLens README、复用边界、贡献和安全文档
- [x] 建立个人公开 GitHub 仓库
- [x] 创建基线 Issue 和 Pull Request
- [x] 合并并发布 `v0.1.0`

## v0.2.0：轨迹特征与规则异常

目标：形成最小可演示的 RouteLens 差异化功能。

建议拆成三个 Issue：

1. `feat: 轨迹特征提取`
   - 输出位移、速度、主方向、路径长度、净位移比和停留时长。
   - 对短轨迹、重复时间戳和缺失帧有确定处理。
   - 使用合成轨迹编写单元测试。
2. `feat: 逆行与徘徊检测`
   - 逆行基于场景期望方向和持续帧数，不依赖单帧抖动。
   - 徘徊结合停留时长、活动半径和路径长度。
   - 输出事件类型、轨迹 ID、起止时间、指标和阈值。
3. `feat: Streamlit 异常列表`
   - 页面区分基础统计和 RouteLens 新增功能。
   - 可下载异常事件 JSON/CSV。
   - 提供一段可复现实验视频或公开数据来源说明。

## v0.3.0：数据挖掘与路线偏离

目标：用轨迹数据发现主要通行模式，而不是仅靠手写规则。

- 轨迹重采样、归一化与特征向量
- DBSCAN 聚类主路线和噪声轨迹
- 偏离分数与阈值解释
- 参数对比实验及误报/漏报记录
- 小型标注集与评价指标

## v1.0.0：证据卡与稳定交付

目标：完成稳定、清晰、可复查的公开演示。

- 异常关键帧、轨迹叠加、原因、指标和时间组成证据卡
- 一键演示素材和回退方案
- 完整 README、架构图、接口示例、已知问题和 Release Notes
- Actions 绿色，依赖告警已处理或说明
- Pages 项目页与 5 分钟演示讲稿
