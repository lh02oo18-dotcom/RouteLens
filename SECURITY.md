# Security policy

## Supported versions

Only the latest tagged RouteLens release is actively supported.

## Reporting

Do not publish credentials, private RTSP addresses, identifiable private video, or other sensitive data in an Issue. Report a suspected vulnerability privately to the repository owner through GitHub's private vulnerability reporting feature when it is enabled.

## Video and model safety

- Use only video that you are authorized to process.
- Keep raw video, generated outputs, model weights, and local configuration out of Git.
- Do not commit access tokens or camera URLs.
- Review dependency alerts before each release.
- Privacy blur is an aid, not a guarantee of anonymization.
