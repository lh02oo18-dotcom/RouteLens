ROUTELENS · VERSION 1.0.0

看见路线，也看见判定依据。

RouteLens 复用 YOLO 与多目标跟踪，把视频中的轨迹转化为路线模式、异常事件和可复查证据卡。它面向普通个人电脑运行，输出 CSV、JSON、视频和图像证据。

视觉感知人员检测、目标跟踪、计数与轨迹记录
数据挖掘DBSCAN 主路线聚类、路线原型与偏离评分
可解释输出关键帧、轨迹、指标、阈值与证据引用

主路径

视频输入 → 人员检测 → 多目标跟踪 → 轨迹特征 → 路线聚类 → 逆行 / 徘徊 / 偏离 → 证据卡与结构化导出

可复现检查

  • python -m pytest -q：运行全部单元测试
  • python -m tools.route_mining_demo：运行合成路线参数扫描
  • python -m tools.evidence_demo：生成证据卡回退演示
  • python -m streamlit run app.py：启动本地交互界面

合成实验只验证计算与导出链路。真实视频的 Precision、Recall 和 F1 必须使用许可明确的视频、独立人工标注及冻结参数后报告。
